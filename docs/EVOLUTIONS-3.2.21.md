# Gear Control 3.2.21 — logiciel fabricant déjà ouvert au démarrage

Complète la [priorité au logiciel du fabricant](EVOLUTIONS-3.2.20.md) introduite en 3.2.20.

- Si le logiciel du fabricant est déjà ouvert quand Gear Control démarre, le périphérique apparaît tout de suite en orange et verrouillé, avec ses derniers réglages enregistrés. C’est aussi le cas pour les périphériques enregistrés par une version antérieure à la 3.2.20.
- Pendant ce temps, la détection Windows générique ne liste plus ce même matériel une seconde fois dans **Ajouter un périphérique**.
