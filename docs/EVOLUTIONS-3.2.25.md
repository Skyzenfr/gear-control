# Gear Control 3.2.25 — historique des versions

- L’onglet **Mises à jour** des réglages généraux affiche l’historique complet des versions, de la plus récente à la plus ancienne, regroupées par série (3.2, 3.1, 3.0…). Chaque version se déplie pour lire ses notes. La version installée est mise en avant et ouverte par défaut.
- Les notes viennent des fichiers installés avec Gear Control : l’historique reste lisible sans connexion. Quand GitHub répond, les versions publiées affichent leur date de publication et un lien vers leur page. La liste des versions publiées est gardée 30 minutes pour ne pas épuiser le quota anonyme de GitHub. Si GitHub est injoignable, la dernière liste connue reste affichée.
- Gear Control retient désormais la date d’installation de chaque version sur ce PC et l’affiche dans l’historique.
- Un champ de recherche filtre l’historique par version, titre ou contenu des notes, par exemple « Stream Deck » ou « DualSense ».
- Une nouvelle version proposée affiche un lien « Voir sur GitHub ». En bas de l’onglet, trois liens mènent au dépôt GitHub, à la page de tous les installateurs et à la page pour signaler un problème. L’adresse du dépôt sous l’interrupteur de recherche automatique est maintenant cliquable.
- Seuls les liens `https` vers le dépôt configuré sont affichés comme liens. Les notes venues de GitHub sont affichées comme du texte, jamais comme du HTML. Les installateurs restent téléchargés uniquement à partir du manifeste signé.
