# Gear Control 3.2.38 — Alertes de batterie, automatisations par appareil et sauvegarde

- **Alerte de batterie faible** : quand un appareil passe sous le seuil choisi (15 % par défaut), Windows affiche une notification et Gear Control un message. Une seule alerte par décharge ; elle revient après une recharge. Réglage dans **Réglages généraux → Autonomie**.
- **Historique des batteries** : la même page montre l’évolution du niveau de chaque appareil sur 48 heures ou 7 jours. Survolez la courbe pour lire l’heure et le niveau exacts.
- **Batteries dans la zone de notification** : le menu de l’icône Gear Control liste le niveau de batterie des appareils connectés.
- **Automatisations selon vos périphériques** : dans **Réglages généraux → Automatisations**, lancez une scène quand un appareil se connecte, se déconnecte ou passe sous un niveau de batterie (par exemple : basculer le son sur les enceintes quand le casque passe sous 10 %).
- **Sauvegarde de la configuration** : dans **Réglages généraux → Mises à jour**, enregistrez en un fichier vos périphériques, noms, réglages, scènes et profils, pages Stream Deck, action épinglée et préférences, puis restaurez-le sur ce PC ou un autre. La clé de télécommande et la connexion Spotify ne sont jamais incluses. Une copie de la configuration remplacée est conservée.
- Pour les contributeurs : mode simulateur, enregistrement des échanges USB et guide de capture d’un protocole (`docs/CAPTURE.md`).

Téléchargez **GearControl-Setup-3.2.38.exe** pour installer ou mettre à jour Gear Control sur Windows 10 ou 11, 64 bits.

La publication inclut l’empreinte SHA-256 de l’installateur et le manifeste signé `latest.json` pour les mises à jour automatiques.
