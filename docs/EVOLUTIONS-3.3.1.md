# Gear Control 3.3.1 — Profils de jeu et automatisations

- **Profils de jeu** : choisissez les réglages à inclure et modifiez leurs
  valeurs dans le profil, sans changer immédiatement les périphériques.
  Les claviers disposent aussi des réglages par touche pris en charge.
- **Jeu et Bureau** : associez un profil à `cs2.exe` ou à une autre application,
  puis choisissez un profil Bureau indépendant. Le retour peut avoir lieu
  dès que le jeu quitte le premier plan (Alt-Tab) ou à sa fermeture.
- **Automatisations** : créez et modifiez une règle directement dans
  **Réglages généraux → Profils & automatisations**. Déclencheurs disponibles :
  connexion, déconnexion, batterie faible, lancement ou fermeture d’application.
- Combinez jusqu’à huit actions : choisir une sortie audio, ouvrir une
  application locale, envoyer un raccourci clavier ou appliquer les réglages
  d’un profil. Le sélecteur de fichiers permet de choisir Steam ou une autre
  application installée, sans saisir son chemin.
- **Raccourcis manuels** : enregistrez une suite d’actions sans déclencheur et
  lancez-la depuis le panneau ou le menu des profils dans la barre supérieure.
- Correction de la liste des scènes servie au menu et à la télécommande.
  Les automatisations autonomes conservent le suivi du profil de jeu actif.

Exemples : connexion des INZONE → sortie audio INZONE ; connexion de la
DualSense → ouverture de Steam ; lancement de CS2 → réglages clavier pour le
jeu ; retour au Bureau → réglages clavier habituels.

Les actions utilisent les fonctions déjà prises en charge par chaque
périphérique. Gear Control doit rester actif ; la page du navigateur peut être
fermée. Les essais automatiques utilisent des périphériques simulés et des
applications factices.

Installateur : `release/GearControl-Setup-3.3.1.exe`.
